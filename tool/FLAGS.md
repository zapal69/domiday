# assets/flags/

Флаги стран для карточки «Сейчас» и списка «По странам».
Источник: flag-icons (https://github.com/lipis/flag-icons), лицензия MIT
(текст в assets/flags/LICENSE-flag-icons.txt), набор 4×3, снято 14.09.2026.
SVG растеризованы QuickLook (macOS) на белом квадрате 256×256; флаг 4:3
вырезан геометрически (строки 32–224, без обрезки по альфе — иначе
остаются белые полосы) и уменьшен до PNG 160×120. SVG-рендерера в
приложении нет. Имена файлов — код ISO 3166-1
alpha-2 в нижнем регистре; записи без кода флага не имеют.
