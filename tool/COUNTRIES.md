# assets/countries.json

Справочник стран ISO 3166-1 alpha-2 с названиями на английском и русском.
Источник названий — CLDR-данные JDK (`Locale.getDisplayCountry`), снятые
14.09.2026 (Java 17); поверх — короткие привычные названия для показа
(США, Южная Корея, Кыргызстан, Гонконг, Макао, Северная Корея) и таблица
синонимов для сопоставления старых текстовых записей. Косово (XK) добавлено
вручную. Формат: `{code, en, ru, aliases?}`. Территории вне списка
остаются в дневнике свободным текстом без кода.
