## Хранение

`trips.json` в `getApplicationSupportDirectory()`. Снимок schemaVersion 4:
`trips`, `homeCountry`, `homeCountryCode`, `current`, `undated`.

У завершённых поездок: id, country, countryCode (nullable), city, note,
arrival, departure, kind (stay | transit; отсутствие — stay). Даты: YYYY-MM-DD. Текущее пребывание: id, country,
countryCode, nullable arrival, confirmedOn, nullable notBefore.
Неполный архив: id, country, countryCode, departure.

Миграции v1→v2→v3→v4 не меняют значения и идентификаторы прежних записей;
v3 только добавляет коды по точному совпадению текста со справочником
(assignCodes при загрузке), v4 — поле kind, старые записи считаются
пребыванием. Чтение не записывает новый файл; новая схема появляется при
успешном сохранении. При ошибке миграции/сохранения исходный файл не
заменяется пустым. Старые версии приложения новый файл не откроют.
Текущая страна никогда не выводится автоматически из последней старой поездки.

Сохранение выполняется через временный файл, flush и переименование в том же
каталоге. Операции сериализованы. Повреждённая или неподдерживаемая история
блокирует запись. Отдельного шифрования файла или PIN нет.

## Функции 0.18.2 (по аудиту Astra: временные копии файлов, дата копии)

- Аудит Astra от 17.09.2026 (статический разбор APK 0.18.1 и прогон в
  эмуляторе). Принято владельцем: пункты 1 и 3 ниже.
- `FilePickerStore.open()` после чтения выбранного файла (успех, отмена,
  ошибка) вызывает `FilePicker.clearTemporaryFiles()`: плагин на Android
  копирует файл в `cache/file_picker/`, а экспорт Хронологии содержит
  координаты. `pick`/`clear` подменяются в тестах
  (`file_picker_store_test.dart`).
- `restoreBackup` после успешного восстановления вызывает
  `markBackup(createdAt файла)`: раньше сразу после восстановления
  показывалось «копии ещё не было».
- Принятые риски и пояснения (не меняем):
  - Сертификат подписи имеет DN `CN=Android Debug, O=Android, C=US`. Это
    не стандартный debug.keystore Android Studio: ключ лежит отдельно
    (`<папка с ключом вне репозитория>/domiday-prototype.keystore`), защищён паролем
    владельца, имя досталось от параметров по умолчанию при создании.
    Сменить нельзя без потери обновлений у установивших; Play и Android
    DN не проверяют.
  - В плагине file_picker (android_file_picker 2.0.0, FileUtils.kt:758)
    проверка `canonicalPath.startsWith(safeDir)` без разделителя: имя из
    `_display_name` поставщика документов может вывести копию за папку
    `file_picker/`, но только внутрь кэша приложения; для этого нужен
    вредоносный поставщик, выбранный пользователем. После очистки кэша в
    0.18.2 там ничего ценного не остаётся.
  - Не сделано (решение владельца): выбор «только по кнопке / также при
    открытии» при первом разрешении; подпись «только транзит: N» у
    счётчика карты; формулировка «раз в 2–3 часа» → «периодически».

## Правила и известные ограничения

- День приезда и выезда включён. Пересечения объединяются. Суммы по странам
  могут быть больше общего числа дней из-за пограничных дней.
- Без известной даты приезда текущее пребывание не добавляет даже одного
  предполагаемого дня. История с неизвестным началом видна отдельно.
- Неизвестные дни: 1 января → сегодня для текущего года, полный прошлый год.
- Домашняя страна меняет классификацию во всех годах, но не историю записей.
  Периоды смены постоянного места жительства пока не моделируются.
- Начальные/конечные пробелы вне известных пребываний не предлагаются
  автоматически. Предпросмотр защищён от изменений состояния и смены даты.
- Названия стран свободные; нет словаря синонимов «США / USA».
- Для подтверждённого переезда есть нижняя граница даты правки.
  Более раннюю историю можно добавлять вручную.
- При совпадении новой текущей записи со старой поездкой обе записи
  сохраняются без молчаливого удаления; объединение дней исключает удвоение.
- Дата обновляется при возвращении в приложение и с интервалом до 30 секунд
  при непрерывной работе. Часы телефона считаются достоверными.
- Нет GPS, фонового определения, уведомлений, сервера, аккаунта, рекламы,
  аналитики, экспорта, резервных копий, будущих поездок, визовых/налоговых тестов.
- Android debug/profile-манифесты содержат стандартное разрешение INTERNET
  для инструментов Flutter. В проверенном release APK его нет.
- На другой ОС golden-сравнения могут отличаться из-за рендеринга:
  сначала изучить diff, не заменять эталоны вслепую.
